# Linux Daily Labs

A hands on Linux learning journey documenting
my daily practice, experiments, and
troubleshooting as I build my Linux skills
for a career in cybersecurity.

## About This Repository

This repository contains practical Linux labs,
command references, notes, Bash scripts, and
security exercises performed in my Linux
virtual machine.

My goal is to understand Linux by practicing,
documenting, and applying concepts in real
environments.
